## Why

shows them consistently in AR/EN catalog and POS/cart, and retains an accessible fallback.

### Production media gate
- These are externally hosted illustrative pilot references, not assets with verified A1 republication rights.
- **Before any public/commercial deployment** obtain licensed/authorized manufacturer or distributor images,
  save reviewed media in A1-owned storage with attribution/rights metadata, and verify file integrity.
- Prevent third-party CDN hotlink failure by migrating to A1-owned approved media before launch.
- Use correct SKU/version/color imagery. Do not silently substitute a similar phone.
- Never treat test prices, demo stock, transaction history or images as proof of real inventory.
- Preserve meaningful alt text, AR/EN accessibility and a non-broken fallback for unavailable media.

### What is not claimed
- The four external hosts have not been verified reachable from the target deployment.
- No live staging URL has been launched by this PR.
- Accessories and spare parts still display neutral placeholders pending licensed exact-model images.
