# A1 Mobi — Preliminary Visual Direction

Decision date: 2026-09-28. Owner-approved visual reference: TriAssistant's card layout, clear sectional composition, and responsive color movement on hover or focus. This is a presentation and interaction reference, not a color reference.

## Application

- Arrange operational information in legible cards with clear grouping, hierarchy, and enough spacing for Arabic and English.
- Use restrained color transitions and local hover/focus highlights to show the active card or action; preserve keyboard focus visibility and reduced-motion preferences.
- Keep default A1 Mobi colors suited to a mobile-phone shop. Tenant administrators can later customize logo, name, colors, phone, email, and social accounts through tenant branding settings.
- Apply the same interaction language consistently to dashboard, POS, inventory, repairs, Device Trust, and administrative surfaces; adapt layout for desktop and mobile widths.
- Keep primary operational actions obvious. Visual effects must not obscure IMEI trust status, prices, totals, errors, or permission boundaries.

## Gate and scope

This is a preliminary design decision for future UI work, not a declaration that those screens are complete. The Master Implementation Brief remains authoritative for all store workflows.
